Curiosity is the
starting point.

A practical learner building toward security operations.

I'm an aspiring cybersecurity professional interested in the work behind a good security investigation: collecting evidence, connecting signals, and explaining what the evidence actually shows.

I learn best by getting hands-on. That means examining suspicious email indicators, working with Windows telemetry in a small SOC lab, practicing security concepts in labs, and writing small scripts to reduce repetitive investigation steps.

I'm currently strengthening my foundations in security monitoring, incident investigation, and security automation as I work toward a SOC Analyst, Cybersecurity Analyst, or Security Operations role.
